## 功能与修复

- 保留完整 premium 玻璃的模糊、折射、形变、回弹及胶囊播放器开合。玻璃几何仅在实际尺寸或几何变化时失效，减少重复 matte 生成；合成缓存同时比较变换和离屏 pass 范围。
- 识别 Material 3 回弹的 `ImageFilterLayer`，即使 render transform 没有移动也检查合成范围。震动与手机登录按钮继续蓝底白字。签到、听歌领取、广告领取三个按钮保持白底黑字；页面同色底层在滚动离屏 pass 内绘制，避免回弹时玻璃采到透明底层变灰。滚动赢得手势时取消按钮按压高光，正常点击、键盘反馈和光学动效保留。
- 当前 Beta 移除不可用的 Mesting 登录/注册入口，旧找回路由转向现有账号入口。正式渠道的 Mesting 功能和原素材源码继续保留；不执行凭证或用户数据清理。
- 69 项正式渠道专用素材不再进入 Beta APK。仍在使用的 IP 进度条、角色、经典唱片预览与有效页面素材保留。构建前清理经过路径校验的 Beta 生成资源暂存目录，构建后检查 APK，避免 Flutter 暂存残留使旧图片继续入包。
- “装扮 → 进度条角色 → 小新”提供太阳、微风、夕阳、夜晚、细雨、雷雨、游行七种天气，独立手动选择，持久化成功后更新选择。离屏预览及系统关闭动画时停止无效 ticker，当前选中效果保持。
- 新增两张用户原始 PNG 静态启动页，整图按比例完整显示、同色留白。Beta.19 首次升级统一切到图一一次，之后保留用户重新选择；两段原视频与经典页保留。静态启动没有固定停留或视频解码，Beta 移除 720ms 最短启动等待，玻璃与音频依赖并行准备。正式渠道原启动契约保留。
- 账号恢复异常覆盖层补齐独立 Material、文本和安全区上下文，避免出现巨大的红色下划线诊断字体；重试与重新登录仍由原账号控制器处理。启动诊断默认关闭，只在显式编译开关下记录时间和错误类别，不记录账号凭证或异常消息。

## 有效的真机性能对比

设备为小米 14 Pro（23116PN5BC），Android 16，120 Hz。采用 Flutter 3.41.9 的
Profile 构建，在独立 `com.mesting.music.beta.benchmark` 包中运行同一份测试。
偏好使用内存夹具，首页为生产页面，胶囊显示相同的静止本地封面，不播放音频。
测试实际校验入口覆盖层已释放，并逐次校验胶囊收起/展开和真实滚动位置。
每次以 360ms 受控滚动往返，共八轮，使用真实时间和设备 vsync 采集 FrameTiming。

| 指标 | Beta.18 | Beta.19 |
|---|---:|---:|
| 采集帧数 | 933 | 1080 |
| Build 耗时 P95 | 7.290 ms | 5.466 ms |
| Raster 耗时 P50 | 7.284 ms | 6.141 ms |
| Raster 耗时 P95 | 31.684 ms | 25.311 ms |
| Raster 耗时 P99 | 40.547 ms | 30.234 ms |
| 超过 8.33ms 的帧占比 | 36.87% | 31.39% |
| 超过 16.67ms 的帧占比 | 13.18% | 11.85% |

Raster P95 下降 20.11%，P99 下降 25.43%，Build P95 下降 25.02%。
阈值使用该帧 Build 与 Raster 两阶段耗时的较大值，计数均来自已记录帧。
没有把帧数除以整个测试时长冒充实际显示 FPS。

这是一组受控场景对比，不能认证所有页面持续 120fps；完整效果下仍有超预算帧。
也没有取得足够等条件的进程 CPU 占用率对照，不能宣称“CPU 100% 已彻底解决”。
线上播放、热机、后台任务和不同机型仍由后续真机使用验证。早期未校验入口门控或
完整开合的测量已被本组替代，不作为交付数字。后一次系统 trace 因 ADB 连接失败未
取得，已有 Dart CPU 栈采样不等于进程占用率。

## 真机测试工具事件与剩余测试包

早期执行 `flutter drive` 时未指定 `--keep-app-running`。Flutter 3.41.9 的
`FlutterDriverService.stop()` 默认会停止并卸载测试应用，因此日常 Beta 曾被卸载，
原登录态和原本机数据保留无法认证。这是测试流程失误，已向用户说明；没有提取或
伪造凭证，后续安装成功或当前首页显示账号不能作为原数据完整保留的证明。

后续改为独立 `.beta.benchmark` 身份、内存偏好并保留应用运行。
`tool/run_beta19_native_profile.ps1` 强制校验 APK 包名，只允许独立测试包，
显式使用 `--keep-app-running`，ADB 安装失败时停止。

用户随后要求自行真机测试并断开手机，已停止所有手机访问。设备上可能仍留有同名
图标的独立测试应用：`com.mesting.music.beta.benchmark`。它可在确认包名后移除；
日常 Beta 包名为 `com.mesting.music.beta`。正式渠道未安装、卸载或更改。

## 主机回归与复现

最终统计见交付目录 `validation/test-summary.json`。Beta.19 专项包含 10 项，检查
保存、迁移、布局失效、离屏 pass、静止合成更新、减少动画及恢复异常页可读性。
正式渠道使用 `flutter test --flavor stable`，确保按真实渠道构建带 flavor 的素材清单。

正式渠道保留三个既有失败：

1. `editing menu leaves its gap outside the complete multiline field`。
2. `rose colors are limited to declared brand and heart roles`，涉及旧 `player_queue_panel.dart` 的 `#F04F58`。
3. `follower removal sheet stays above the persistent player`。

它们已在先前 Beta.17/Beta.18 基线中复现，本次不将它们混入新修复或声称全量通过。

构建 Release：

```powershell
./tool/build_android_md3_beta_apk.ps1 -FlutterSdkRoot '<Flutter 3.41.9 SDK>'
```

独立原生测试需先在工程副本中把 Beta 的 applicationIdSuffix 改成 `.beta.benchmark`，
以 `MESTING_ISOLATED_BENCHMARK=true` 编译对应 integration target，再使用
`tool/run_beta19_native_profile.ps1` 运行已构建 APK。不得直接对日常安装执行默认
`flutter drive`。冻结 Beta.18 APK/源码 ZIP 保持原哈希。
