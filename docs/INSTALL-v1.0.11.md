# Mesting Music 1.0.11 安装与双平台验收

安装包：`Mesting-Music-v1.0.11.apk`，Android code32，包名 `com.mesting.music.beta`。原签名与现有安装一致，可直接覆盖升级；不要先卸载，以免删除本机各账号队列与进度。

安装前可核对文件大小 **101,655,441 字节**，SHA-256：

```text
3F63EE0B26584C3DB2CD6AB0A953B859E132773F288BABB26B2BEFB80617F8E5
```

发布完成后的公开下载入口为 [Mesting Music 下载](https://download.csnas.asia/music/download)。具体发布状态见 [本版接续](SESSION-HANDOFF-2026-10-28-v1.0.11.md)。

已有酷狗账号升级后继续使用原账号。新增平台从“我的 → 切换音乐平台”进入；欢迎页按“酷狗登录、网易云登录、游客”排序，各平台进入后显示自己的登录方式。网易云扫码需要使用该平台支持的扫码方式确认；手机验证码、手机密码和邮箱密码也在同一组选项中。

建议按下面顺序验收实际账号与设备行为：

1. 在酷狗播放一首歌，记录歌曲、队列顺序和进度；进入“我的 → 切换音乐平台”，登录网易云。
2. 确认酷狗已暂停，网易云展示自己的资料、收藏和歌单。播放网易云歌曲并形成自己的队列。
3. 切回酷狗，确认无需重复登录，原歌曲、队列和进度恢复，播放器保持暂停；手动继续播放。
4. 再切回网易云，确认恢复其自己的记录并暂停。关闭应用后重新打开，确认最后选择的平台与其登录状态恢复。
5. 在其中一个平台明确退出登录，再选择另一个平台，确认另一平台的登录状态仍在。重新登录退出过的同一账号后，确认原播放快照可恢复。
6. 检查搜索、歌词、音质、评论、歌单管理和 MV，以及浅色/深色、键盘、玻璃控件、底部胶囊与过渡效果。会员或版权歌曲以当前账号接口返回权限为准。

本机已验证相关自动化回归、原签名、APK 结构与公开匿名协议；上述真实账号和手机体验由用户亲自操作验收。没有在用户手机执行安装、ADB 或性能测试。
