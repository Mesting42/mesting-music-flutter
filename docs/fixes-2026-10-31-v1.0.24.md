# Mesting Music 1.0.24 / Android code45

本版在既有 1.0.23-r2 工作区上实现五组已确认需求。原 R2 APK 与所有冻结产物保留；原签名、包名 `com.mesting.music.beta`、双 ARM、定制 Flutter 3.41.9 Release 引擎和完整玻璃继续沿用。本轮没有手机安装、ADB、Git 提交/推送或后台发布。

签到入口进入统一网易云/酷狗双标签页。酷狗日历、会员状态、平台确认记录、签到、手动领取与验证码复用原控制器和业务仓库。保存的酷狗身份独立于当前听歌平台，日常自动签到可在网易云模式生效；账号/日期去重，账号退出或替换先撤销旧作用域。网易云签到同样有独立保存身份与代次。所有请求不临时替换共享播放器 API 会话；迟到结果不写回新账号。

网易云官方完整音频优先，失败或只返回试听时先尝试已保存的酷狗概念版账号，再保留既有公开补源链。逐曲来源选择新增“酷狗概念版账号”。候选仍严格核对歌名、歌手、专辑、录音版本与时长，解析后的队列身份、评论和歌词继续使用原网易云歌曲。账号请求只走独立酷狗作用域，CDN 探测与公开来源不发送账号鉴权。MP3 帧和 FLAC STREAMINFO 决定实际音质，16-bit FLAC 不能因请求 Hi-Res 被标成 Hi-Res；指定下载档位不足仍失败并保留选择。缓存和内部后续请求一并受账号撤销、取消与超时保护。

下载状态明确区分等待、解析、下载、保存、完成、失败与取消。解析阶段使用自定义蓝色波形，下载与版本更新共享 `AppleDownloadProgress`，显示真实已下载/总大小和 KB/MB；未知总大小明确展示。网络 100% 仍属于保存中，发布文件成功后才移入已下载。任务页只显示未完成项，失败/取消可重试，空任务显示“暂无下载任务”。取消后立即重试采用独立尝试代次，旧解析或保存结果不能复活任务。两页支持横滑、点击联动与独立纵向位置。

音效社区/耳机/明星改为独立保存的分页，补齐真实封面候选字段与耳机嵌套载荷。匿名官方响应确认部分封面来自 `mobileservice.bssdl.kugou.com` 的 HTTP 地址，该主机 HTTPS 证书不匹配，原先全体酷狗域名升级 HTTPS 导致图片失败。现仅精确保留该已核对公共图片主机的官方 HTTP，其他主机策略与 TLS 校验保留。没有伪造图片或关闭证书校验。

下载、本地歌曲/文件夹、音效、网易云通知分类支持真实横向分页；已有历史/社交 TabBarView 仅增加活跃页纵向通知转发。Root Navigator 二级音乐页面复用发现页的 `BetaMusicBottomBar` 与 `FloatingPlaybackPill`，移除原来只有搜索的后备底栏和额外底部背景盒子，保留玻璃取样背板。输入法真实显示时隐藏胶囊，收起后即使筛选仍生效也恢复；键盘高度只应用一次。聊天与评论已有玻璃输入栏，明确由原输入栏拥有底部，避免导航覆盖发送。窄屏大字号保留展开胶囊以容纳播放/切歌控件。

流畅度诊断新增 App 内连续双平台生产页面巡检、进度/停止、错误/超时继续、逐段保存、崩溃断点续跑、完成后返回诊断页和独立 Release JSON 文件分享。清单、适用条件、排除原因与数据边界见 [诊断场景说明](DIAGNOSTIC-SCENARIOS-v1.0.24.md)。报告显示中文汇总及数值指标；未登录、无数据、不适用阶段记跳过，零帧与导航失败不记通过。运行前抑制跨平台自动签到及奖励验证；不执行发送、领取、购买或删除。

主机回归、静态分析、原生编译、APK/源码校验结果以 [验证报告](validation-2026-10-31-v1.0.24.json) 为准。独立正式 APK、源码 ZIP 与摘要在 [安装交付说明](INSTALL-v1.0.24.md) 中列出。主机和匿名目录检查不替代真实账号权益、手机 GPU、完整诊断一轮与一起听双端验收。兼容恢复避开已确认的驱动路径，不能宣称永久修复 Adreno 驱动或持续 120 FPS。
