# 1.0.15 / code36 本地 SVIP 与原生补源

用户已确认 App 直连、无需额外音源登录、官方 → 新音源 → BugPk，以及本地 SVIP 展示与补源联动。本轮准备原签名 APK、完整源码 ZIP 和校验资料，music 由用户上传发布。1.0.13、1.0.14 冻结产物保持。

## 模块与数据流

- `netease_playback_options.dart`：本机会员策略、按 UID 保存的开关、可选 UID 名单、音源设置及防御性恢复。默认启用本地 SVIP，仅当前网易云账号生效，不改认证接口返回值或安全会话。
- `netease_membership_page.dart`：本地会员页面及个人页徽标，管理当前账号和 UID 范围。开启当前账号本地 SVIP 时同时开启补源，关闭不抹除已有播放设置。
- `fallback/netease_fallback_source.dart`：独立适配接口和录音匹配。精确网易云 ID 适配器与跨平台元数据适配器分开。
- `fallback/netease_public_sources.dart`：固定上游的 B站音频、WBI 视频音轨和 GD Studio Dart 适配。无 Node 服务、证书拦截或外部下载程序。
- `netease_fallback.dart`：先完整官方流，失败/试听后进入新音源组，最后 BugPk。普通顺序依次尝试；最高音质模式至多同时处理两个音源，整体有时间预算。登录失效、验证码或风控错误不伪装成补源问题。
- `netease_source_settings_panel.dart`：沿用“网易云播放与同步”，统一管理来源、策略、无损、最低码率、缓存和 JSON 诊断。会员接口入口转入本地会员页，自动流程不请求无用原始表单。

备用流保留网易云曲目 ID、封面、歌词、收藏/评论及播放上报关联。匹配要求歌名、歌手、版本和时长；未知时长或翻唱/现场等版本差异拒绝。跨平台已知专辑不一致时拒绝，B站没有专辑字段时必须有明确表演者/标题以及时长证据，不能把视频分类当成歌手。视频在解析实际播放信息时复核标题和时长。

音源的公开 Referer/User-Agent/Origin 随 Track 传至探测、播放器和下载；Cookie/Authorization 不进入 Track、历史或媒体元数据。B站元数据请求可在适配器内临时使用匿名访客 Cookie，绝不携带网易云账号。切回官方时清除旧备用源的媒体头。

真实 FLAC 前缀检查是“无损”通过的必要条件。最低码率设置作用于备用流，未知码率在设定下限后拒绝；最高音质使用返回值而非请求值。AAC/DASH 的实际 bitrate 单独保存，不标成 320k MP3。官方完整音频始终优先，不因备用最低码率而替换官方流。

解析缓存最多 32 个、45 秒，命中仍进行小范围音频探测，过期/403 重取，换账号重建。只读诊断保留最多 80 条来源、结果、耗时及码率，不含歌曲、身份、凭据或完整 URL，可手动复制 JSON 和清空。缓存设置控制音源解析缓存，现有音频播放器缓存独立。

## 来源状态与已知限制

| 来源 | 本版处理 |
| --- | --- |
| 酷狗、酷我 | 复用匿名适配；酷狗沿用现有 Android 内嵌 Rust 通道，无新增服务部署。酷我实际返回可用性依网络及平台变化。 |
| B站音频、视频音轨 | 原生匿名接入，严格匹配后使用音频地址，保留 HTTPS 和必要公开媒体头。不会直接把搜索第一条当同曲。 |
| GD Studio | 适配与入口保留，默认停用。本机匿名请求曾返回 HTTP400：`source` 不受支持，生产客户端复测遇 HTTP403，均不能作为可用音源。 |
| 波点 | 入口保留、停用。上游链路包含广告观看完成上报，本版不直接复制该事件；独立匿名完整播放尚未证实。 |
| YouTube | 入口保留、停用。地区/动态签名解析尚未验证；不捆绑 yt-dlp/youtube-dl 或 Node。 |
| QQ、咪咕、JOOX | 按用户决定不纳入需要个人凭据的来源，不复用上游公共代码中的共享会话。 |
| BugPk | 最终补源阶段，精确网易云歌曲 ID，保留已有请求间隔和受限官方外链解析。 |

本地 SVIP 只提供本机展示与尝试入口；服务端会员任务、购买、平台权益仍以平台实际响应为准。没有制造真实会员开通、真实时长或平台奖励。
