# Mesting Music 1.0.17 / code38 安装与复测

请使用本版原签名APK自行更新。包名和证书与1.0.16核对后记录在`release/Mesting-Music-v1.0.17-verification.json`；本机没有执行手机安装，不能把身份核对说成真机升级已通过。保留旧版冻结APK与源码，不清除应用数据。

1. “我的”：检查资料区、快捷入口、创建和收藏歌单；进入播放与同步应直接显示设置。
2. 二、三级页面：分别试标题返回、系统返回、左和右边缘返回，应只退一级；检查页面切换流畅度。
3. 浅色与深色：从“保存UID范围”和其他玻璃按钮开始拖动列表，保持手指不抬起，按钮按压应取消且无灰色实底；同时检查加载与禁用状态。
4. 私信：阅读最新消息返回后检查会话和总未读；之后收到的新消息应重新显示未读。只翻阅旧消息或在后台轮询不应清空新未读。
5. 搜索：中文拼音组合、确认选词、连续增删文字、清空；已有结果保留到下一次结果到达，加载状态不应逐字重启。
6. 切歌：点歌后旧歌立即停止、胶囊立即显示新歌和加载；连续选择只播放最后一首。失败后点击播放重试；解析过程中暂停不应被迟到请求恢复。
7. 封面：创建／收藏歌单在列表与网格检查；第一次在线加载后再检查缓存。
8. 下载：先选一个系统允许的音乐目录，下载后从“已下载”单曲／播放全部；开飞行模式并重启App后再播放。播放全部顺序与页面一致。
9. 文件：从已下载单曲菜单导出副本、打开所在文件夹；切换新下载目录后，原歌曲仍应能播放。删除／移动文件或撤销授权应提示恢复，不应自动播放在线版本。
10. 选源：在网易云歌曲菜单选择自动／官方／既有来源；检测中的或暂不可用的来源应置灰不可点，重新检测可刷新结果。当前账号酷狗音源与双签到联动本轮未新增。

真实音源可用性和会员权限由平台决定；本地SVIP不会改变官方账号权限。用户自行上传发布，本轮未操作发布后台。
