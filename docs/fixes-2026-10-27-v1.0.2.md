# Mesting Music 1.0.2：音乐首页与设备输出

2026-10-27（Asia/Shanghai）。用户确认本轮作为**正式发布 1.0.2 / Android versionCode 23**，上传现有 Ring Download 的 **Mesting Music · music**，并验证 1.0.1 的应用内更新发现与下载。内部 flavor `beta`、包名 `com.mesting.music.beta` 和原签名继续保留，只作覆盖升级兼容身份；不切换到旧 stable 产品界面。本次授权不包含手机访问或 Git 提交/推送。

## 当前实现

- 版本值紧跟“当前版本”，使用 12dp 间距及大字可换行的 `Wrap`，不再用 `Expanded` 将值推到远处。
- 当前渠道“我的”移除装扮，保留“设置 → 装扮”；指南路径同步调整。旧 stable 渠道原入口独立保留。
- 耳机图标统一为 Tabler MIT `device-airpods` 的细线改编：24 单位坐标、1.65 单位描边；工具栏/当前设备 40dp，列表 29dp。没有打入 Apple SF 字体或产品符号。原 SVG、来源与许可在 `third_party/audio_glyphs/`，应用内开源许可也可离线查看。
- “切换设备”在原 premium 玻璃卡片内展开“本机”和已连接媒体输出，取消自动系统选择器及次级系统设备管理按钮。新设备先由用户在系统完成配对。
- 原生适配层只操作当前音乐 owner 的真实 AudioTrack，并同步同一个 ExoPlayer 的 preferred device；不新建播放器，不切通信模式，不断开全局蓝牙。换曲/音轨重建保留进程内偏好，旧实例释放不能清除新音轨。活动输出须经路由回读；暂停选择明确显示“已选择，播放时生效”。
- 首页保留当前 Apple Music 布局、封面、语义色和光学，加入猜你喜欢、新歌首发、热门榜单、新碟、主题及场景音乐和真实目录/详情入口。推荐由当前账号的酷狗响应及服务端顺序决定；账号/token 变化拒绝旧请求。
- 场景详情先读取 `/scene/module`，仅选择 `module_type=2` 内 `content_type/types=6` 的实际标签，再调用 `/scene/audio/list`；排除视频、听书和讨论，不以通用推荐冒充场景内容。主题使用 `theme_id`。
- 当前协议等公开文案改用“Android 版/当前版本”。自动听歌时长上报、暂缺联系方式和两项历史测试问题不在本轮修复范围。

`.codex-artifacts/2026-10-27-music-refinements/` 保存回归、原生编译、生产注册器 JVM 断言、20 张生产 Flutter 控件主机捕获和复核。截图使用合成账号/目录/版本、样例封面和 Windows QA 字体；两张初始浅色图的图标未解码，已在原路径重拍。1.0.1 是旧版原生信息夹具，实际发布身份以 APK 核验为准。主机证据不替代 Android GPU、真实蓝牙、实际账号推荐或手机安装验收。

最终计数、APK、源码快照和线上验证结果以本版交接及核验文件为准；各组重叠不可相加。旧 1.0.1 APK/源码 ZIP 保持冻结。

## 构建与接续

正式构建入口为 `tool/build_android_release_apk.ps1`，默认 1.0.2/23，内部沿用兼容 flavor。Dart 锁仅将 just_audio 0.10.6 换为仓库内同版本分支，其他 Dart 依赖版本未升级；Media3 1.9.2 原已由 video_player_android 解析，本轮显式固定。补丁说明见 `third_party/just_audio/NOTICE.md`。
