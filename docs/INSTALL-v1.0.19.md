# Mesting Music 1.0.19 安装与复测

公开版本 1.0.19，Android code40，保持 com.mesting.music.beta 与原签名。使用 release/Mesting-Music-v1.0.19.apk 覆盖安装；实际签名、大小、摘要及构建状态见同目录 verification JSON。1.0.18 的旧冻结文件保持。本轮本地准备不等于已上传 music 或 GitHub。

1. 覆盖 1.0.18，检查账号、播放队列和下载记录保持。
2. 网易云“我的”检查创建/收藏歌单真实封面；发现页检查林俊杰、薛之谦等歌手榜图片，滚动返回后仍显示。慢网可先占位再加载。
3. 网易云与酷狗分别从歌曲菜单下载，在入队前选择实际存在的音质，检查下载任务显示档位；下载途中改变播放音质，排队任务应仍使用原选择。验证无权限、降档或试听时明确失败，不伪装成功；重试保留原选择。批量下载检查共同支持档位。
4. 和网易云官版互发普通表情，检查 [便便] 等历史表情变为图案。表情按钮内部和面板各行均居中；点击表情仍插入草稿，不自动发送。
5. 聊天好友名称居中且稍减字重。一起听位于右上菜单左侧；窄屏耳机入口有提示且可进入原功能。返回、刷新和更早消息正常。
6. “我的消息”显示所有未读总数，0 不显示，99 显示 99，100 及以上显示 99+；阅读、返回消息页、切后台再回来后应刷新。切换账号不能短暂出现另一账号的未读数。
7. 发现页网易云专区不再出现重复“音乐搜索”；底部搜索可搜歌曲和歌手，关闭搜索及返回正常。
8. 浅/深色与大字号下检查聊天、下载选择和玻璃按钮。从按钮上起手滚动并保持按住，确认高亮/形变恢复，正常轻点仍有效。
9. 使用相同手机和相同切页路径重新录制诊断，比较绘制分位数和体感，尤其是首次进入发现、返回“我的”、播放中切页。保留玻璃效果；主机检查没有证明持续 120fps。

真实双平台下载权益、用户私信与消息计数、ROM 保存目录和更新后手机帧率由用户复测。本轮代理没有操作手机、ADB、真实音乐账号或发布后台。
