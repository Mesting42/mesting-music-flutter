# Mesting Music 1.0.14 / Android code35 验收

只使用 `release/Mesting-Music-v1.0.14.apk`。正式显示名Mesting Music，包名 `com.mesting.music.beta`。证书、版本及包结构以相邻verification JSON为准，不用build目录的临时包代替交付包。旧1.0.13冻结包及源码ZIP保留。

建议按以下顺序自行验收：

1. 覆盖安装后确认版本1.0.14，已有登录、音乐库与队列保留；本机没有连接手机代测。
2. 网易云歌曲进入评论，标题应为网易云评论，点赞/回复/拥抱及资源类型正确；切到酷狗后仍是酷狗评论。
3. 播放一首网易云歌曲，不等播完就在官版刷新最近播放；暂停、缓冲和拖动不应虚增实际时长。同步页区分回执与云端确认，官方索引可能延迟。
4. 官方仅有试听或无权限的歌曲检查备用音源，确认来源与实际音质，尝试切换音质。若BugPk没有完整返回，不应宣称已经取得完整版。
5. 我的 → 我的消息中直接进入会话，发送文字和表情，选择图片、预览再发送，检查官版接收；评论、@我、粉丝及通知的分类与分页。发送失败先刷新历史再重发。
6. 从歌曲菜单或聊天页打开一起听，邀请使用官版的好友；检查接受、播放/暂停、切歌、拖动、队列、离开页面、后台恢复和主动结束。当前尚无真实双端互通验证。
7. 对音乐库、云村、曲风、播客、会员云贝、音乐人等分类检查真实权限内容及选择器。已下架入口应明确提示平台暂不支持。
8. 检查底部玻璃搜索、聊天键盘避让、浅/深色、大字号、按钮起手滚动时手指未抬起即恢复按压状态；均衡器应标注本地来源。

music上传由用户操作，选择最终APK并核对发布JSON中的版本、code、大小与SHA-256。源码ZIP留作接续，不上传至music，不公开签名材料。验证JSON中的本地通过不代表已经线上发布或经过真机验收。
