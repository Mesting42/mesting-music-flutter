# Mesting Music 1.0.3：资料、播放工具与禁用状态

2026-10-27（Asia/Shanghai）。用户已逐项确认本轮范围、实现及正式发布到现有 music 后台，目标为 **1.0.3 / Android versionCode 24**。内部 flavor `beta`、包名 `com.mesting.music.beta` 与原证书继续用于覆盖升级。用户自行真机测试，本轮没有访问手机或使用 ADB。

## 本轮行为

- 修复共享玻璃按钮和图标操作的禁用前景/底色配对，分别适配浅深色。关闭触感时，“体验触感”文字仍可辨认，指针、键盘焦点及可用语义同时关闭；开启后才以功能蓝突出并可点击。保留完整玻璃光学、回弹及滚动取消按压行为。
- 版本更新抽屉新增“查看此次更新”。已是最新版也可查看精确匹配的内置说明；未来没有正文的版本不借用旧说明。
- 新增当前酷狗账号的头像、昵称、性别、生日、个性签名及省市地区编辑。只提交变更字段，JSON body 传递资料/头像，失败保留草稿，账号或凭证变化拒绝旧结果。头像先本地预览，再明确上传，实际结果受平台审核。离线地区覆盖 31 个内地省级地区，保留目录外的原有资料值。
- 新增作用于现有音乐播放器音频会话的 Android 均衡器。使用设备返回的频段/增益范围，九个预设及自定义设置持久保存，切歌后重新绑定会话。原生初始化移出 UI 线程，带超时和迟到结果守卫，不创建第二个音乐播放器。
- 均衡器拖动点按用户确认统一为 **6dp**，轨道约 **2dp**，无滑块阴影和按压放大，保留 **48dp** 响应区及频率/分贝语义。
- 音效目录使用现有社区、耳机、明星 endpoints，免费可用条目按原版规则映射到真实均衡预设，应用后保存。页面说明实际能力；没有声称实现 IRS/VPF 卷积。搜索仅筛选已加载目录。
- 新增歌曲 MV 元数据、真实播放地址、清晰度、全屏、进度及播放控制。进入暂停当前音乐；退出仅在进入前正在播放、歌曲身份与后续命令未改变时恢复。用户或定时器的后续暂停优先。媒体域名按原版返回的酷狗 CDN 有界放行，更新链继续 HTTPS。
- 定时关闭支持预置、自定义倒计时或播完当前歌曲，届时暂停并抑制自动下一首；保留应用及账号。曲终计时暂时关闭原生单曲循环以获得真实结束事件，随后恢复用户原播放顺序。计时不跨进程保存。

## 关键接续点

共享按钮在 `lib/shared/widgets/beta_glass_{controls,action}.dart`；工具页壳为 `music_feature_page.dart`。资料模型、repository、离线地区和页面各自分离于 `features/music_platform/`。均衡核心和定时器位于 `core/audio/`，Android 桥接在 `MusicEqualizerPlugin.kt`，所有播放工具均复用 `MestingAudioHandler`。

资料、免费音效映射、均衡曲线、MV 和计时功能参考 md3Music v6.1.0，固定提交 `4f783a998d7a108685dfa2e3dc9449df9c474c4e`。移植及地区许可见 `third_party/md3music/MESTING-1.0.3-PORTS.md` 和 `third_party/region_data/`。沿用已有 Dart 依赖；`pubspec.lock` 与 1.0.2 保持相同。
