# 1.0.15 / code36 用户安装与验收

使用最终 `release/Mesting-Music-v1.0.15.apk`。核对同目录 verification、SHA256 和发布字段；不要使用 build 中的临时包。正式显示名 Mesting Music，包名 com.mesting.music.beta，原签名；是否可覆盖以 APK 身份核验及设备实际安装为准。

1. 网易云账号进入“我的”，检查本地 SVIP 徽标和“我的会员”；关闭、重开、切换账号后检查各自状态。
2. “我的会员”保存指定 UID，检查名单外账号不出现本地会员。留空恢复每个账号的本地开关。
3. “网易云播放与同步”检查官方 → 新音源 → BugPk，音源开关、顺序/最高音质、最低码率、无损和缓存。不存在同一录音时应失败或明确试听，不能播搜索第一首替代。
4. 播放器音质选择是尝试入口，最终展示应跟随实际文件；B站补源后测试暂停、拖动、后台及下载。失效地址重试应重新解析。
5. 开启音源诊断后重试一首歌曲，检查仅本机记录并可复制 JSON、清空；关闭后不新增日志。
6. 检查浅深色、大字号、玻璃按钮起手滚动和底部搜索；不通过关闭玻璃/动画改善表现。

GD Studio/波点/YouTube 停用入口有原因提示，勿当作已验证可用。未代测真实账号、会员专属曲目、实际安装、后台或官版双端互通。用户自行上传 music，不把本机准备标成已发布。
