## 代码接手

- `app_update_release_source.dart`：只负责平台公开元数据的解析、边界校验和映射；稳定/Java 通道的旧源保留。
- `app_update_repository.dart`：唯一文件下载、续传、完整性及安装接口。随机本机下载 UUID 与按 origin 分开的下载会话仅保存在应用本地，不包含管理后台凭据。
- `app_update_providers.dart`：单一操作 owner，避免重复下载/重复打开安装器；存储不可用时显示可恢复错误。
- `beta_app_update_sheet.dart` / `apple_download_progress.dart`：状态呈现和进度动画；不自行创建第二个下载任务。
- `beta_activity_indicator.dart`：独立绘制可见的八笔画等待标记。Flutter 自带 Cupertino 标记最高 alpha 为 147/255，故仅改源颜色为白色不足以解决蓝色玻璃上的对比度。
- `tool/build_android_md3_beta_apk.ps1`：默认 1.0.1/22，并开启 `ENABLE_APP_UPDATE_CHECKS`。共享正式 `pubspec.yaml` 版本不随内部 flavor 发布更改。

## 使用与发布边界

旧平台公开名称 1.0.0 对应用户上传的 Beta.20 文件，实际 code 为 20。旧 Beta.20/21 尚未包含本轮更新入口，需先手动覆盖安装一次 1.0.1，之后的新版本才可由本功能提醒、下载并打开系统安装器。以后每次上传都必须提高 APK 内真实 versionCode，修改平台显示名称本身不能触发可靠升级。

本轮测试、包核验、平台发布及源码快照的最终结果见 [1.0.1 交接](SESSION-HANDOFF-2026-10-27-v1.0.1.md) 和 `docs/version-archive/v1.0.1-evidence/`。主机截图使用合成版本/下载数据，不证明 Android GPU 材质、TalkBack 或原生安装已通过。没有访问手机或执行 ADB；本版由用户自行真机测试。自动听歌时长上报继续关闭。
