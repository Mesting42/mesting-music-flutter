# Mesting Music 1.0.12 安装验收

原签名包名 `com.mesting.music.beta`，Android code33。使用 `release/Mesting-Music-v1.0.12.apk` 覆盖安装，保留本机登录、队列和进度。安装包摘要以相邻 `.sha256` 和验证 JSON 为准。

1. 登录网易云，分别检查发现、功能、音乐库、我的。不得出现酷狗听书、识曲、一起听、会员奖励或酷狗社区音效目录；本地均衡器、定时和本地音乐继续可用。
2. 检查网易云推荐、分类、排行榜、歌手／专辑／MV、播客、收藏和音乐云盘。真实账号受限功能如实显示平台结果。
3. 检查歌曲／MV／专辑／歌单评论的排序、回复、点赞和本人删除；这些操作只在用户主动点击时写入。
4. 从播放器更多菜单或长按歌曲下载，在下载管理查看进度、取消、重试。完成后到本地音乐播放，检查FLAC等实际格式和系统文件。云盘上传选择文件后有明确确认，删除云盘文件保留本地原文件。
5. 原本可完整播放的《陪你去流浪》继续使用网易云原音源；另选原接口确实不可播／只有试听的样本检查备用链和来源。设置→网易云播放与同步可关闭补源。
6. 检查云端最近歌曲／歌单／专辑与听歌排行。实际播放后再检查上报状态；接口接收不等于官方累计时长已经入账，拖动不应虚增本地实测秒数。
7. 两平台切换前暂停并保存原账号歌曲、队列和位置，切回后保持暂停；退出一个平台不清除另一个平台登录，也不删除播放快照。

发布到 music 与真实手机验收分别记录。没有新的明确授权，代理不访问手机。
