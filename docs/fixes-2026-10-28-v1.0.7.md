# Mesting Music 1.0.7 修改与验证

日期：2026-10-28。基于已发布的 1.0.6 / code 27 工作区继续实施，用户已确认 1.0.7 / code 28 与 music 后台发布。保留原有所有未提交变化及冻结交付，不自动提交或推送 Git。

## 界面与导航

- 底部导航改为“发现／功能／音乐库／我的”。现有首页内容保留并改名“发现”，原发现根页成为固定三列功能网格；每日推荐、收藏和已有详情深链接继续可用。
- 固定网格提供私人 FM、每日推荐、搜索、排行榜、精选歌单、听歌识曲、听书、场景音乐、一起听、听歌回顾、新碟、音效，以及发现／收藏／本地音乐常用入口。未实现的上游功能不作为空入口展示。
- 顺序／随机及循环关闭／列表循环／单曲循环分别使用不同 glyph。
- 播放器收起和更多按钮共用同一款圆形 premium 玻璃按钮。菜单起点在按钮朝向菜单的一侧内缘，保留 400ms 展开、240ms 收回、液态连接及反向轨迹；编辑菜单继续使用原锚点。

## 新增功能

- 本地音乐：MediaStore 扫描、SAF 多文件及目录导入、持久化授权、按文件夹浏览、搜索、失效条目状态与离线播放。索引原子保存，元数据在后台提取，封面惰性加载并缓存无封面的结果。设备库独立于酷狗云收藏；扫描只由用户显式操作触发。
- 听歌识曲：麦克风权限、8 秒分段录音、最多 7 轮；PCM16/单声道/8kHz 转换在 isolate 中执行，支持 RIFF 扩展 chunk、静音判断及有界归一化。识别结果复用原歌曲身份、播放和收藏；无 hash 时按准确录音 ID 或歌手／歌名匹配来源。
- 一起听和听书复用当前酷狗账号及唯一音频引擎。房间授权和听书地址由各自 repository 解析，临时签名地址不作为长期授权缓存。具体协议与状态测试保留在对应 `release_107_*` 测试中。

## 播放历史与实际时长

- schema 6→7 增加按账号隔离的持久化同步 journal，旧数据只迁移可还原的歌曲、累计次数及最后活动时间，不制造旧播放片段。
- 用户已接受：旧 625 分钟继续完整留在本地；不伪装成今天新播放，不承诺补回酷狗原月份。
- 本地与官方同步共用单调墙钟计时，排除暂停、缓冲、seek；倍速不把实际时长翻倍。只有具备酷狗歌曲身份的 `kugou_32hex` 参与同步，听书和本地文件排除。
- 官方历史上传、CSCC 事件及等级累计增量各有状态。写前先持久化 dispatched；超时保留 unknown，不盲目重发。独立官方读回才能标为 verified。“刷新同步状态”只核对，不重放排队写入。
- 设置提供同步开关及已接收／已核对／待发送／待核对状态。此前两轮接口成功但无实际入账的证据仍有效，本轮主机协议测试不能代替真实账号入账。
- 应用内 Beta 协议与隐私政策更新至 10 月 28 日，说明音频扫描／SAF、短段识曲录音与清理、酷狗房间与播放统计的真实用途和关闭入口，移除“尚未启用自动上报”的过期描述；不新增虚构联系主体。

## 性能与验证边界

- 保留完整玻璃模糊、折射、形变和回弹。交互期间，同一帧的多个玻璃控件共享完整 DPR 背景纹理并克隆句柄，避免重复创建全屏纹理；每个新帧更新，兼顾嵌套重绘边界、视频和平台纹理。
- 胶囊收展与底栏布局隔离，选中标签的文字／图标内容在形变 tick 期间复用。相同主机 336 帧、8333us 节拍场景中，widget builds 从 1.0.6 的 22726 降为 21426，约 5.7%；这是结构性工作量证据，不是真机帧率证明。
- Android 同时请求同分辨率高刷 window mode 和 Flutter Surface frame-rate hint，在 surface 重建后恢复请求；操作系统仍有最终调度权。
- 设置新增可手动采集的 90 秒逐帧诊断，报告 UI／光栅／总耗时、屏幕刷新率与匿名切换标记，不包含歌曲、账号或凭据。以 120Hz 的 8.33ms 为目标，不把主机 pump 次数、截图或显示模式当作实际 120fps。
- 本轮不访问手机、不使用 ADB、不安装或读取用户真机；真实 MediaStore/SAF、麦克风效果、双端房间同步、官方实际入账、持续 120fps 与覆盖升级仍由用户验证。

构建、安装包摘要和最终发布读回记录见同版接续文档及忽略目录 `.codex-artifacts/2026-10-28-release107/`。
