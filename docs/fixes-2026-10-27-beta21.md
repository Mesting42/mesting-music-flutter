# Beta.21：队列、首次使用与设备选择

日期：2026-10-27（Asia/Shanghai）。基于 `beta` 分支的 Beta.20 未提交工作区继续修改，Git HEAD 仍为 `edc6d1bf881cbe2173709cc84b86b91637fbaaed` / `v1.0.37-beta.19`。本轮只交付新的本地 APK 和源码快照，不提交、建标签、推送或发布。

## 已确认的行为

| 需求 | 实现与边界 |
| --- | --- |
| 播放列表视觉与交互 | 弹出队列和播放器内待播列表共用 `BetaPlaybackQueue`。保留真实待播顺序与自动推荐来源，支持拖拽手柄排序、左滑移除和无障碍上下移动/移除操作；随机播放和循环为独立控件。拖动中列表变化时按歌曲身份重定位，避免移动错误歌曲。移除待播歌曲不替换正在播放的音频。 |
| 小提示去掉绿色对勾动画 | Beta 日常操作提示保留文字、语义播报和触感；成功 check 不再挂载。专用登录成功 HUD 独立保留。不是移除全部绿色状态或设备选中标记。 |
| 首次法律弹卡 | Beta 不再自动叠加首次协议卡片；不会因此写入同意状态。欢迎页显式勾选及协议/隐私政策链接保留，登录流程继续验证用户选择。正式渠道原逻辑保留。 |
| 手机登录输入框滚动变灰 | `BetaGlassScrollBody` 在 overscroll 离屏合成内绘制真实页面底层。手机号、验证码继续使用原 premium 玻璃材质和形变，不通过降低光学效果解决问题。 |
| 法律内容 | 新增按 Beta 渠道选择的当前版用户协议/隐私政策，说明酷狗手机/扫码、安全验证、真实平台请求、会话与本地存储、播放记录、设备路由和权限、历史云账号边界。会员奖励以服务端真实结果为准；没有宣称听歌时长已真实入账或可由本客户端删除第三方账号。联系方式按用户要求暂未填写，本文不是法律合规认证。 |
| 八页新手指南 | 按现有五类搜索、播放器/歌词/评论、账号与收藏、真实队列手势、音频输出、启动/天气与五种播放器样式重新组织。插图可以点按演示，示意交互不发请求、不播放音频、不写账号数据。指南末页复用欢迎页角色；减少动画时直接切换页面。 |
| 欢迎角色及补充站位 | 使用原启动插画中的黑胶唱片与奶油色耳机身份，唱片坐在左下，耳机在右侧搭肩。新透明 2×2 组合姿态图集中保存原组合关系；默认显示小写 `hi` 气泡和三条手指提示线，挥手/点按时弹动，配合眨眼、点头和轻跳。属于 3D 渲染图像的 2D 姿态动画，未宣称拥有新的骨骼 3D 模型。后台、不可见及减少动画时停止计时动画。 |
| 音频输出选择 | 点“切换设备”在同一玻璃卡片内展开设备列表。只展示系统公开的当前与可转移路由；等待原生确认并读回当前路由后才显示切换成功。配对、新设备和系统不公开的操作保留用户已接受的“系统设备管理”入口，系统卡片由系统决定样式。 |

## 主要接手位置

- 队列：`lib/features/queue/presentation/beta_playback_queue.dart`；弹层/播放器只负责承载，业务仍由 `MestingAudioHandler` 持有。
- 输入底层：`lib/shared/widgets/beta_glass_scroll_body.dart` 与 `platform_account_page.dart`。
- 首次进入与法律：`disclaimer_dialog.dart`、`legal_documents.dart`、`legal_documents_page.dart`；欢迎页原显式同意键保持。
- 欢迎/指南：`beta_companion_stage.dart`、`beta_guide_preview.dart`、`beta_onboarding_page.dart`。素材及完整内置 image_gen 提示词见 `assets/branding/welcome/provenance.json`；最终位图为同目录 `companions-atlas.png`。旧的两张独立角色试制图已移出交付，原始两张启动 PNG 字节保持。
- 输出设备：`audio_output_controller.dart` 为 Dart 状态/确认边界；`AudioOutputBridge.kt` 为公开 Android 路由桥；`player_output_routes.dart` 为卡片内列表，视觉和原生调用解耦。
