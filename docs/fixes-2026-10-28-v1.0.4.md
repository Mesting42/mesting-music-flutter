# Mesting Music 1.0.4：P8P 更新下载 SDK

用户已确认先发布 1.0.3，再按 `Music-P8P-SDK-交接包-20261027.zip` 接入 SDK；接入后以 **正式 1.0.4 / Android code 25** 在同一个 music 后台发布。1.0.3 的 APK、原始源码 ZIP 和核验结果保持冻结。本轮没有手机访问、安装或 ADB 操作。

## 实现范围

- 当前维护产品沿用 beta flavor、`com.mesting.music.beta` 和原签名；不切换旧 stable 产品界面。
- 通过本地 path 依赖编译 Ring Download SDK 1.1.0。启动时不下载 SDK 源码，音乐播放也不进入 SDK。
- 保留 `CsnasUpdateReleaseSource` 的 music/health 发现、真实 APK code 比较、发布快照、大小和 SHA-256 契约。SDK 接收选定清单，不重新替业务选择版本。
- 生产 `RingAppUpdateTransport` 只持有一套 SDK，固定 `appId: music`、`enableP2P: true`、`enableP8P: true`、`allowSharing: false`。用户端不上传分享文件；有可用节点时接收辅助分片，HTTPS 立即开始且由 SDK 处理恢复及主副源切换。
- 暂停等待 SDK 写入收尾，保留进程内进度；重开进程可能暂时显示 0，续传时由 SDK 回报真实缓存进度。旧 HTTP `.partial` 继续按原 Range 协议完成一次，后续新任务采用 SDK 缓存格式。
- 完成后 Music 再次核验大小和 SHA-256，原子 rename 至原安装白名单目录，避免额外复制整份 APK。安装前继续核验，统计不把打开安装器视为安装成功。
- 主动下载涉及的随机安装标识、网络地址、传输诊断及 P2P/P8P 接收在当前隐私说明中如实披露；分享仍关闭。没有新增后台系统通知或自动安装能力。
- 内置 1.0.4 更新说明；保留 1.0.3 六项资料编辑、均衡/音效、MV、定时关闭、禁用状态修复及 6dp 均衡圆点。

## 合并与构建环境

交接补丁基于 `95d5719829a754978ba615a873aa6ddff08f67f6`。两个更新模块与该基线一致，补丁在含 1.0.3 改动的工作区检查通过后应用；1.0.3 新增文件、离线地区及更新说明没有被覆盖。当前工作分支为 `codex/release-1.0.4`，源码修改尚未 commit/tag/push。

宿主继续使用独立 Flutter 3.41.9 / Dart 3.11.5，符合 SDK 声明约束。没有升级全局 Flutter；依赖锁按本机重新解析后 `pub get --enforce-lockfile` 通过。与 1.0.3 相比增加 SDK、Dio、WebRTC、元数据等必需依赖；Windows 侧的 win32/安全存储实现随兼容约束调整，旧音频/资料/视频依赖未升级。精确锁摘要及 APK 身份见同版交接。

SDK 原始 ZIP 共 196 文件，194 项逐字节一致；一处生产文件只去除多余非空断言，另一个测试文件修正读取宿主 pubspec 的错误工作目录假设。原始 ZIP 不修改。两处差异和原许可见 `third_party/ring_download_sdk.SOURCE.md`；没有为历史 contention 场景改变 SDK 传输策略。

## 验证记录

- 宿主更新接入及 1.0.3 相关回归 80 项通过；旧 stable 选定兼容 18 项通过。
- SDK 六个合同/传输文件首轮 213 通过、1 个元数据夹具路径失败。定位为从 Music 根目录读取了 Music 自身版本；路径修正后该项隔离复测通过。原始失败日志保留，不将首轮写为全绿。交接曾记录的 contention-repeated 场景本机首轮已通过，不能据此承诺所有设备或网络都成功。
- 全项目分析无问题；后续修改处的定向分析也无问题。
- 真实 SDK 默认引擎在 Windows 主机下载线上 1.0.3 签名包，2MiB 后暂停、恢复、整包校验和安装目录移动通过。主机返回 `platform_unsupported` 并走 HTTPS，未冒充 Android P8P 连接或实际节点贡献。
- Android 首次构建因直连 Maven 长时间无数据而主动终止了本次自建 Gradle 进程；重新构建使用当前电脑已有代理，仅在构建进程中设置 Java HTTP/HTTPS 代理，未改全局网络配置或关闭证书校验。该次主动停止不计为源码编译缺陷。

最终 Android 构建、签名、完整下载及后台发布结果以同版交接记录为准。所有主机证据均不能替代真实手机覆盖安装、音频/视频、前后台及厂商网络行为验收。升级到本版的过程由旧客户端 HTTPS 完成；安装本版后的后续更新才使用新 SDK。

## 保留边界

发现更新仍依赖 music/health；平台停机时不会自动发现独立 COS 新版本。业务已提供外部合法 HTTPS 清单时，SDK 下载可以不请求本站服务；此轮保留原协议，不新增独立发现源。SDK 私有源码不因本机集成自动获准公开上传 GitHub，包含 SDK 的源码快照仅在本机私有保存。
