# Mesting Music 1.0.19 / Android code40

基于 beta / 8763551c0cc39c1c25f60e42fd49624f58d91a89，按用户确认的七项修复方案准备本地交付。构建、回归和签名的最终状态以同日 validation JSON 与 release 核验为准；本轮没有后台发布、Git 提交推送、真实账号操作或手机/ADB 访问。

## 封面和图片开销

网易云公开歌手榜匿名返回的原图样本为 10,082,816 字节，同一资源的 510×510 CDN 缩略图为 299,640 字节，响应为 200/image/jpg。原图进入通用封面组件时既增加网络、解码及 GPU 上传负担，也可能超出磁盘缓存校验范围。现在在 ArtworkImage 的统一请求边界为已知网易云图片 CDN 按控件尺寸生成有界缩略图，创建/收藏歌单和歌手栏自动受益；不开放全局明文网络，不改写其他 CDN 的签名。缓存区分缩略图尺寸，仍合并同尺寸的过期签名刷新；尺寸变化重新绑定图片。空字段、裸文件名或图片 ID 不再遮住后续有效 URL。

## 独立下载音质

新增 audio_download_quality.dart，单曲与批量入口都先选择音质，再确认系统保存目录并检查保留的账号身份。网易云读取实际歌曲资源字段，酷狗读取对应音质资源哈希；不借用播放模式本地 SVIP 的“可尝试”列表制造下载档位。批量只提供当前这些歌曲共同支持的档位，最多并发三个元数据请求；没有共同档位时提示逐曲下载。

AudioDownloadTask 独立保存 requestedQuality，持久化、排队、取消后重试与重启恢复都保留该值。任务不再在开始时读取后来变化的全局播放音质。网易云按真实 level 下载，酷狗按对应资源哈希严格解析；既有补源也必须满足选定档位。平台降档、未知档位和试听不能伪装下载完成，失败会保留明确提示。资源存在不等同于账号拥有下载权益，后台和真实账号未在本轮写入或验收。旧的无音质字段下载记录继续兼容。

## 消息和聊天

普通方括号表情在展示边界转换为对应 Unicode 图案，覆盖用户样本 [便便] 和常见官版表情；原始消息载荷保留，未知自定义贴纸保留原文字。此项不声称获得或完整嵌入官版专有贴纸素材。表情面板居中，按钮取消多余内边距并明确居中图案，继续使用公共玻璃控件。

聊天标题使用对称测量的布局在整页水平居中，字重为 w500。一起听置于右上菜单左侧，正常宽度显示文字，窄屏使用带“一起听”提示的耳机入口；左侧返回保留。菜单支持刷新与读取更早消息，不发送额外消息或自动发起一起听。

“我的消息”聚合私信、评论、转发/提及、通知、新粉丝等服务端计数；正数显示，超过 99 为 99+。前台每 30 秒合并读取，恢复前台和返回消息页重新刷新；阅读游标触发即时本地修正。新账号重新加载期间隐藏旧值，不跨账号复用徽标。临时计数失败不自动宣称全部已读。

## 搜索与切页

移除发现等网易云专区中的重复“音乐搜索”导航入口，保留底部搜索和原内部搜索契约。新增 RouteSettledContent，让可选推荐栏在真正入场完成后再启动网络和图片工作，避免 Flutter 首次 offstage 测量时的临时 complete 动画代理提前放行。已加载内容在返回或手势过程中保留；未改玻璃质量、按压形变、返回曲线或动画时长。

此次性能工作包含有界 CDN 图片、尺寸缓存与切页可选任务调度。原始诊断的统计和限制见 PERFORMANCE-2026-10-30-v1.0.19.md；主机检查不能代替更新后手机的持续帧率测量。

## 维护入口

下载队列/存储、下载能力/选择 UI、表情展示、未读数据、路由可选任务分别放在独立模块。新增回归为 netease_v119_data_test.dart 与 netease_v119_ui_test.dart；原按钮按住后拖动取消、双平台、下载存储、账号隔离和搜索返回用例一并回归。版本历史与 APK 随包说明同步到 1.0.19/code40。
