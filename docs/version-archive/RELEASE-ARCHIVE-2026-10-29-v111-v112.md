# Mesting Music 1.0.11、1.0.12 版本归档来源

本次按用户确认的完整归档范围保存两个版本的提交、固定标签及 GitHub Release，维护入口为 beta，main 和历史版本保持。提交创建于本次归档，不伪造历史开发时间。

每个版本的源码来自对应原始冻结 ZIP：1.0.11 / Android code32 有1553份源文件和一份 SOURCE-SNAPSHOT.json；1.0.12 / code33 有1582份源文件和一份快照说明。所有原始条目逐文件核对大小、SHA-256、ZIP CRC 与 Git blob，APK 和原始 ZIP 不重建、不重签、不重压缩。标签只追加归档来源说明和版本来源清单；下一版本保留前版新归档清单。GitHub 自动生成源码包包含这些追加资料，与原始 ZIP 附件不同。

SOURCE-SNAPSHOT.json、版本验证 JSON 和冻结交接中的 gitCommitted:false、gitPushed:false 描述冻结时状态，保留原始字节。最新 Git/GitHub 状态应核对远端标签、Release 和 beta 的跨电脑接续说明。版本标签之后的 beta 提交只补充归档证明、校验文件和接续文档，运行源码、素材、测试及依赖锁保持 1.0.12 冻结字节。

GitHub 版本归档与 music 更新后台分别记录。既有核验记录确认 1.0.11 已发布到 music；1.0.12 已完成原签名构建，但当时因内置浏览器连接不可用而尚未上传或发布。本次 GitHub 归档不改变 music 后台状态。

源码保留原 LICENSE、第三方声明及已获用户公开分发授权的 SDK；不重新许可第三方内容。SDK appId=music，P2P/P8P 接收开启、用户分享关闭。应用签名私钥、密码、管理凭据、真实账号记录、本机配置和构建缓存不进入 Git 或 Release。tiny_http 原上游公开 TLS 示例密钥只保留与已有基线完全相同的测试夹具字节，与应用签名无关。

归档复核已有主机验证证据：1.0.11 的17文件150项、1.0.12 的26文件273项回归通过，静态分析均无问题；本次未重跑历史产品测试或访问手机。真实账号写入、覆盖升级、系统文件导出、后台下载、音源长期可用性与官版听歌时长入账仍按原验收边界处理。
