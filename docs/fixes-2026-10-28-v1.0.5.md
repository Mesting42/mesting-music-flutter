# Mesting Music 1.0.5 / code 26

用户确认范围：保留完整 Apple/Cupertino 玻璃光学、胶囊开合和 6dp 均衡圆点；1.0.3、1.0.4、1.0.5 同步 Git/GitHub，music 后台仅发布最新 1.0.5。用户自行真机验收，本轮无手机访问、ADB 或安装。

## 行为与实现

- Track 在展示边界统一去除末尾已知音频扩展名，覆盖缓存/历史恢复、列表、胶囊、完整播放器和系统媒体标题。原始标题仍用于 JSON 持久化；ID、路径、hash、Live/伴奏说明不改。
- 定时关闭从 root navigator 的应用主题创建整张弹层，避免继承播放器局部深色 Theme 后混用浅色背景。时长、选中态、说明与按钮一致。
- 完整播放器更多菜单移除重复的“查看歌词”，样式归入默认折叠的“封面样式”，显示当前值。原封面/歌词交互继续工作，胶囊快捷菜单的歌词入口保留。
- 输出设备仅在播放器工具栏中按统一光学尺度绘制；输出卡片/设备列表维持原尺寸和实际路由语义。
- 资料、MV、均衡、音效、触感页复用 BetaGlassScrollBody，将真实 surface 绘制在滚动合成内部；欢迎页同样补上同色背景。没有关闭 overscroll、降低玻璃质量或用平面按钮替代玻璃。
- MV 全屏由独立 presentation 模块管理横屏请求、系统栏和竖屏恢复。复用同一视频控制器，退出返回原详情与清晰度/进度，系统 Back 和退出按钮共享防重入逻辑，等待逆向过渡完成后再恢复内嵌视频。
- 音效列表不再下载旧封面缩略图，使用主题感知的本地图形，按耳机、汽车、空间、低音、人声、电子等类别区分；目录、版权归属、免费预设映射及真实均衡行为不变。
- 胶囊和输入框长按菜单共用 BetaLiquidMenu。Flow 固定测量菜单，动画仅改绘制变换；同一 premium 层的菜单、短颈和源形状在 Impeller 进行 SDF 融合、分离。反向动作沿同一路径融合回真实来源，不使用包住玻璃的透明离屏层。Skia 沿用既有光学回退；系统减少动画时直达终态。
- 输入框继续由 EditableText 处理实际选择、复制、剪切、粘贴、格式化与 IME；取消和执行动作等待收回，页面/音频业务不进入材质组件。
- 底栏附件的宽度、高度及垂直位置改为单一几何时钟，保留稳定的附件子树；播放器只订阅播放布尔变化，详细 transport 状态留在局部控件。

## 验证边界

测试分组、APK 身份、来源快照及发布状态见同版交接和 `docs/version-archive/v1.0.5-evidence/`。原始日志与主机捕获在忽略目录 `.codex-artifacts/2026-10-28-release105/`。

主机捕获使用生产 Flutter 控件、合成账号/MV 画面和不入包的 Windows QA 字体；它们验证可见布局与软件交互，不认证 Android GPU 液态融合、持续 120fps、真实 P8P 节点贡献、真实账号写入或覆盖安装。系统横屏策略和真机手势仍由用户验收。

旧回归的三项期望随本轮要求更新：更多菜单不再有重复歌词；样式先展开再选择；设置新增“播放”标题后，测试应限定胶囊里的播放控件，并将目标设置行滚入安全可点击区域。初轮失败日志保留，不伪写为初轮全绿。
