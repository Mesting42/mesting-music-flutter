- 将指定 Binaryify 文档的剩余接口全部纳入，包括社交、消息、账号安全、会员及音乐人内容。

`sha512-cjjuJ4XBlmklKjWpI1IJRzA6etrhWBCRgk8rtrZZ4JSEPfVmXGLew5DV80owGKSHqnVDAxGQkraxesqX7O2PDQ==`

运行已生成的 App 不需要 npm 或文档抓取服务。只有重新生成协议清单时才需要固定上游包和 `acorn`；生成脚本、独立样本采集脚本都位于 `tool/`，实际解析器版本记录在验证 JSON 中。

清单共 **305 个入口**：文档中的 296 个不同路由（含同一行并列的 `/search`、`/cloudsearch`），以及文档引用示例中的 9 个一起听命令。

- 277 个请求构造器由固定源码转换为明确的 Dart 代码。
- 其余 28 项由既有账号适配、手写请求、上传等组合流程、本地辅助能力或下架说明承接。
- `/login/qr/create` 为本机二维码内容生成，`/inner/version` 为本机兼容版本说明，不伪造网易云网络响应。
- `/comment/hotwall/list` 已被文档标注下架，保留“云村热评”入口，显示“平台暂不支持”，不发送无效请求。
- 逐项入口、源码文件及 SHA-256 位于 `assets/data/netease-full-catalog.json`；便于阅读的完整矩阵位于 `docs/NETEASE-INTERFACE-COVERAGE-2026-10-29.md`。

这里统计接口入口，不是用户打开页面时的请求次数；同一个用户操作可能调用多个接口。

## 页面安排

| 主页面 | 新增分类 |
| --- | --- |
| 发现 | 音乐搜索、音乐探索、榜单与热门、新歌与专辑、歌手、曲风与音乐百科、音乐日历 |
| 功能 | 评论与云村、云村与话题、视频与 MV、播客与声音、歌曲与歌词、乐谱、一起听、听歌工具 |
| 音乐库 | 歌单与收藏、音乐云盘、已购音乐、历史与听歌报告、资料与收藏概览 |
| 我的 | 账号与安全、消息中心、会员与云贝、音乐人中心、兼容信息 |

歌曲长按菜单和资源详情增加相关功能入口。歌曲、歌单、专辑、歌手和用户可以搜索选择，所选内容自动带入操作页。消息可进入相应会话，曲风可继续查看对应歌曲、专辑和歌单，视频和乐谱有对应展示。辅助命令融入账号、上传、识曲和一起听流程。

发送私信、发动态、改绑、密码操作、删除、购买、云贝消费和上传只在用户明确操作并确认后执行；请求超时不会自动重发。数字专辑购买展示平台返回的二维码，支付由用户在支付应用内完成。

确认策略使用逐项核对的 66 条写入路由，不依赖标题关键词。新建歌单、视频收藏及 FM 负反馈也在其中；手机注册状态、点赞统计与签到进度属于只读查询。

一起听有创建、加入、状态、成员、共享歌单、当前播放状态同步和结束操作。前台页面拥有心跳；离开页面、进入后台或账号变化时停止自动同步。离开页面不替用户结束远端房间。跨设备双向行为仍需真实双方验收。

## 全 App 底部玻璃搜索

`BetaPageSearchLayout` 是统一入口，复用原包的 `GlassTabBar.searchable`、编辑菜单、选择控制、玻璃操作按钮和材质配置。

- 页面位于现有音乐 shell 内时，通过 `BetaBottomSearchBinding` 使用 shell 原来的搜索框。
- 独立页面使用相同的官方玻璃组件，搜索放在底部，不再叠加顶部普通搜索框。
- 已统一普通音乐搜索、听书、本地音乐、酷狗音效筛选、新增网易云功能查找、内容选择器和带关键字的网易云任务页。
- 本地列表仍在本机筛选，听书、歌曲和用户搜索仍使用原来的数据来源。
- 清空、返回、键盘避让、窄屏大字体及从控件起手滚动均有专项检查。

## 实现边界与接手入口

- `lib/features/music_platform/netease/full/netease_catalog.dart`：目录模型和中文字段标签。
- `netease_native_routes.g.dart`、`netease_manual_routes.dart`：固定允许列表和原生请求契约。
- `netease_js_values.dart`：固定模块构造请求时所需的值转换，没有动态执行 API 脚本。
- `netease_full_repository.dart`：账号快照、组合步骤和响应过滤。
- `netease_content.dart`：歌曲、资源、消息及人类可读信息的转换边界。
- `netease_upload_workflows.dart`：图片与声音的 NOS 上传；账号 Cookie 不发给 NOS，令牌只发往固定上传主机，音频分片为 10MiB。
- `netease_full_page.dart`、`netease_entity_picker.dart`、`netease_together_page.dart`、`netease_video.dart`：分类、操作、选择、房间和视频页面。
- `lib/shared/widgets/beta_page_search_layout.dart`：统一底部搜索，不持有页面的数据仓库。

识曲的声音指纹在隔离的本地 WebView 内生成，使用固定 npm 分发中的 AFP JS/WASM；该视图无音乐 Cookie，并禁止网络连接，Dart 层单独向网易云发送指纹。保留 MIT 许可和来源说明。原始仓库链接当前返回 404，因此来源依据是固定 npm 分发，不能声称原仓库仍可访问。

`afp.wasm.js` SHA-256：`4926a6d69527a1afbc7f7d120b9c21947e677d80c484c8b65572fa7d4ce3b99f`。本机无网络的 40000 样本烟雾检查生成了 320 字节指纹；这不替代 Android 麦克风和 WebView 验收。

## 验证

- 匿名只读抽查 12 类目录，包括歌手、歌单分类、榜单、专辑、搜索建议、曲风、乐谱、MV、播客、视频分类和国家区号，均返回 code200。另检查了内容解析结构，未执行真实账号写入。

- 最终静态分析 **0 问题**。旧版 26 文件回归、新增功能、公共按钮与搜索回归共 **33 个文件、887 项测试通过**；普通渠道搜索另有 **11 项通过**，使用独立命令，避免不同 flavor 的共享测试资源互相覆盖。
