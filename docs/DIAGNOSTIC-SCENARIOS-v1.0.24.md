# 1.0.24 App 内连续流畅度诊断

入口：设置 → 流畅度诊断 → 一键连续测试全部页面。使用发布版内的真实页面、玻璃、播放队列和本机数据，不需要电脑、ADB 或屏幕坐标脚本。代码清单以 `productionDiagnosticScenarios()` 为准；每次开始会把该轮完整清单写入报告的 `scenarioManifest`。

“全部页面”表示按清单连续巡检可自动浏览的生产页面类型，不表示每个接口、每个列表条目、购买或授权流程都已验收。未登录、无当前歌曲、无详情数据或不适用阶段必须记录跳过。失败、超时与未收到有效帧数据不能算通过。报告中的“已完成采样”也不保证持续 120 FPS 或长期不崩溃。

| 范围 | 实际生产入口 | 数据与行为 |
| --- | --- | --- |
| 两平台四主页面 | `/music/recommend`、`/music`、`/music/library`、`/profile` | 使用各自保存的登录；未登录整组逐项跳过 |
| 主 Tab 超快切换 | `BetaMusicBottomBar.onTabSelected` | 65ms 间隔请求，走现有 `BetaTabNavigation` 合并调度，最后核对“我的” |
| 每日推荐、私人 FM、喜欢 | `PlatformRecommendationDetail`、`PlatformLibraryPage` | 读取真实曲目，不点播放或收藏 |
| 榜单、新碟、歌单、主题、场景 | `MusicHomeCataloguePage`、`PlatformExploreSongsPage` | 详情取实际目录首项；无条目跳过 |
| 网易云各音乐库与发现列表 | `NeteaseFeaturesPage` | 包含歌手、专辑、MV 列表、云盘、收藏、近期内容、排行、播客及历史日推 |
| 网易云实体详情 | `PlatformCatalogDetailPage`、`NeteaseFeaturesPage` | 歌单、专辑、歌手歌曲、播客节目/分类、歌单分类、历史日推均由真实返回实体进入 |
| 播放器、歌词、队列 | `BetaNowPlayingPage` | 公共当前队列与两平台各自队列分别检查；缺少对应平台当前曲目跳过；不自动开始音频 |
| 歌曲评论 | `PlatformSongCommentsPage` | 使用当前歌曲与所属平台，不发评论、不点赞 |
| 网易云消息、聊天、通知 | `NeteaseMessagesPage`、`NeteaseChatPage`、`NeteaseNoticesPage` | 聊天只进入已有会话；粉丝/评论/@/通知分页分别浏览，不发送消息 |
| 音效 | `MusicEffectsPage` | 酷狗社区/耳机/明星分别执行纵滚及分页；网易云使用原本的均衡器页面 |

| 设置与说明 | 设置、主题、均衡器、触感、网易云会员/补源设置、协议与隐私 | 只浏览，不改变偏好或执行交易 |
| 网易云更多功能 | `NeteaseFullHubPage` | 浏览真实功能目录；不把需要业务输入的每个接口表单当成已完成接口验收 |

明确排除并在报告中记录原因：登录、验证码、绑定/注销、头像/背景/歌单编辑与导入、录音/定位系统授权、购买/奖励验证、消息/评论/邀请/上传、会自动播放的 MV/视频详情、Mesting 第三方身份社交、首次引导与睡眠定时设置。排除是为避免自动修改账号、社交内容、系统授权和播放状态，不能计为通过。

每个适用场景分为正常滚动、超快速与反向滚动、左右分页、进入/返回四个阶段。滚动距离取实际 `ScrollPosition` 的窗口与内容范围；快速阶段包含向已加载列表末端及反向回顶，分页会检查实际到达位置。普通页面有序进入，超快速主 Tab 使用生产回调。隐藏、离场、被覆盖或未激活的分页不能拥有滚动操作。

每段复用 `FrameTimingProbe` 原有的 90 秒/14000 帧上限与停止后 1.2 秒末批收齐逻辑，以原始 vsync 边界过滤帧。该轮不把全部帧持续堆在内存中；逐段原始帧文件与汇总检查点单独保存。JSON 包含清单、环境、起止时间、阶段状态、原因、build/raster P50/P90/P99、超过显示帧预算和 16.67ms 的帧数、玻璃绘制计数和原始样本。分享时逐段流式写出并在 Android 后台复制到受限 FileProvider 缓存，分享内容不含账号、歌曲名称、私信、凭据或原始异常文本。

手动停止保留当前位置；真正的进程退出最多丢失尚未保存的一段，重新打开本页可续跑。清单改变的新版不会直接套用旧版游标。平台切换会暂停并保存原队列；结束尝试恢复原平台/游客选择，**不自动重新播放**。恢复失败会显示待手动恢复，不能伪称已恢复。仅打开历史报告不会抑制日常自动签到。

主机回归验证的是编排、取消、报告、真实生产页导航/滚动及布局。1.0.24 手机执行、实际 GPU 帧表现和原生长期稳定性仍由用户后续验收；本轮未访问手机。
