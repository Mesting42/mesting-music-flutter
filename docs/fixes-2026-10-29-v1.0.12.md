# Mesting Music 1.0.12：网易云功能分流、补源与下载

版本 1.0.12 / Android code33。工程仍在 `codex/release-1.0.4` 工作区，本版和 1.0.11 改动尚未 Git 提交／推送。

## 页面与账号

四个主页面保留发现、功能、音乐库、我的及原有玻璃、底栏、播放胶囊和动效。网易云模式使用独立的发现内容和功能入口，移除酷狗听书、识曲、一起听、会员奖励及社区音效目录；这些功能继续在酷狗模式保留。旧路由增加平台访问限制。网易云音效入口转入本地均衡器，不把酷狗目录重命名为网易云音效。

新增推荐／精品／分类歌单、歌手榜与全部歌曲／专辑／MV、收藏专辑／歌手／MV、音乐云盘、云端最近歌曲／歌单／专辑／播客、周／全部听歌排行、历史日推、心动模式及播客电台入口。补齐收藏、订阅、歌单导入任务与进度查询、网易云签到及登录刷新。评论支持网易云热门／最新分页、回复、发布、本人删除和点赞，MV／专辑／歌单可进入对应评论及关联内容。

接口请求格式固定对照 `@neteaseapireborn/api` 4.29.7，功能参考 YesPlayMusic 与 AlgerMusicPlayer（后者固定 f57204d4205769a4457f5975796a35e41785f1d8）。独立执行固定 npm 模块生成了 64 条请求合约样本，Dart 适配逐项通过。未嵌入 Electron、Node 服务、第三方脚本插件或其他平台账号。

## 播放与备用音源

当前网易云账号原音源始终优先。原接口没有地址或只有试听时，默认启用的备用链先通过 BugPk 按同一网易云歌曲 ID 请求，再尝试严格匹配的匿名酷狗／酷我公开音源。跨平台匹配核对标题、歌手、专辑及可信时长，不去掉现场、翻唱等版本特征。无法确认时不替换。

备用链不接收任何已保存的音乐账号凭据；BugPk 只收到歌曲 ID 和请求音质，调用串行限流。返回音质按实际结果保留，播放器更多菜单可查看来源。歌曲仍保留网易云身份，收藏、评论与记录不会写到备用平台。手动音质切换继续遵守原有严格音质契约，失败时保留原流及偏好。

匿名样本检查：33894312《情非得已（童声版）》返回可读取 MP3；1374056689 薛之谦《陪你去流浪》（《尘》）返回 lossless、690326bps、23675094 字节，HTTP206 首段以 `fLaC` 开头。只检查前1024字节，未声称完整下载或解码。后者在用户 1.0.11 中已经可以完整播放，不能用它证明补源能补足原接口受限歌曲；实际受限样本和长期可用性仍待验收。

## 下载与云盘

长按歌曲、播放器／胶囊更多菜单可加入下载；功能和音乐库提供下载管理，支持进度、取消、失败重试。使用网易云 `/song/download/url/v1` 及平台实际提供的完整资源，不把试听片段作为完整下载。下载按文件头识别 FLAC／MP3／Ogg／WAV／M4A，不依赖可能错误的 CDN Content-Type；错误网页不会导出成音频。

单个后台队列以流式方式写入缓存，完成后经 Android MediaStore 保存到 `Music/Mesting Music` 并进入设备音乐索引；旧 Android 使用系统保存位置选择器。文件上限512MB，账号变化取消尚未完成的网络任务，完成的本地文件属于设备音乐库。云盘上传使用单独系统文件选择器，选择后再次确认上传；NOS 只接收上传令牌，不接收音乐 Cookie。原文件保留。云盘上传、删除和歌单导入不在验证中对真实账号执行。

## 播放记录

网易云上报复用单调时钟的实际收听计数器，只计算播放且解码就绪、非拖动的经过时间；暂停、缓冲、拖动与倍速跳过的媒体位置不会虚增秒数。每次播放实例至多一次上报。SQLite 保存发送前状态，接口确认与结果未知分别记录；未知／已发出请求不盲目重发。账号切换保留原 owner 的记录，不把网易云事件交给酷狗同步器。网易云官方累计时长是否入账仍由服务端决定。
