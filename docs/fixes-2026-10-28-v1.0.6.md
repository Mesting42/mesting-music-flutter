# Mesting Music 1.0.6 / Android code 27

用户确认本轮方案与 music 后台发布，随后追加确认修复歌曲页面菜单展开时的左上角异常。用户自行真机测试，本轮不访问手机、不运行 ADB 或安装。

## 修改

- 播放器更多按钮有常驻圆形 premium 玻璃落点。保留原菜单 400ms 展开、240ms 收回、融合短颈与同一路径的中途反向连续性。
- 原 Flow 在 paint 时才保存变换，玻璃祖先却先读取形状坐标，首帧可能读取单位矩阵而在左上角绘制玻璃。改用独立渲染边界，在坐标查询、绘制和命中测试中使用同一帧的变换；菜单内容不随 tick 重建，几何结果在同帧复用。
- 完整播放器菜单与播放胶囊菜单共用内缩圆角行反馈：透光高亮、0.985 倍轻微收缩与复原，取消 Material 灰色水波。键盘、焦点、取消和减少动画的行为保留。
- 顺序播放提示不再附加“不循环”，实际循环和随机逻辑不变。
- 签到日历移除浮动下拉刷新指示器，保留 64dp 阈值的下拉刷新和右上角既有加载指示；同一手势及进行中的刷新合并，不触发签到写入。
- 根应用加入 Flutter 官方中文本地化与 Cupertino 日期文案，生日滚轮显示中文年月日。依赖仅新增 SDK flutter_localizations 及其锁定 intl 0.20.2，既有依赖没有升级。
- 音效列表直接显示酷狗目录的 icon_url/model_icon/logo 原始对应图，按效果 ID 与 URL 进入既有持久缓存，限制解码尺寸并保留失败处理；不再按预设推断复用分类图标。免费目录过滤、均衡预设映射及版权归属保留。
- 页面横向转场使用稳定子树；搜索过渡仅在起止边界隐藏/恢复页面。底栏的搜索控件、导航指示器与输入内容移出弹簧宽度每帧重建路径。光学、折射、胶囊开合、真实几何尺寸与 6dp 均衡圆点保持。
