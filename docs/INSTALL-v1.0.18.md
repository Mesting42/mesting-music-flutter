# Mesting Music 1.0.18 安装复测

版本1.0.18 / Android code39，包名`com.mesting.music.beta`，原证书和双ARM保持。最终APK、大小、SHA-256和签名核验见release/Mesting-Music-v1.0.18-verification.json。本轮准备本地包，不表示已经发布music或GitHub。

1. 使用原签名APK覆盖1.0.17，检查账号、播放队列和已下载记录仍在。无需退出或重新登录账号。
2. 网易云播放页检查音质名称、可尝试档位、切换成功后的实际档位。增强档位不可用或解码失败时应明确提示、保留原流；切到酷狗后仍为原四档。设置和菜单的本地均衡器只保留一个入口。
3. “我的”检查创建和收藏歌单封面、稍减的字重，以及实际等级入口；进入账号与收藏概览，核对Lv、权益和升级要求。接口某项失败时其余内容仍保留，不能把未知等级显示成0。
4. 收藏MV、已购单曲等有内容的账号应显示正常条目；无内容显示暂无。断网请求应显示失败和重试，不伪装空列表。
5. 已下载三按钮同排。在断网状态从歌曲菜单打开所在文件夹，确认定位该歌曲原保存目录；更换新下载目录后旧文件仍按原位置打开。ROM只支持系统文档浏览时，浏览不会改变下载目录。授权失效时应提示重新授权或导出，不提示网络异常。
6. 从“我的”管理下载与存储；设置只显示外观、账号与同步、播放、关于与更新等设置项，账号管理仍可进入，完整个人资料不重复展示。
7. 进入《陪你去流浪》MV，检查播放、重试、各清晰度和全屏进退。其他受限MV按平台返回结果显示，不能以一首匿名首段检查代替所有资源验收。
8. 播放页展开更多菜单，在菜单项上起手上下滚动，手指未抬起时和松开后均不应残留选中高亮；正常点击仍能进入对应功能。浅深色均检查，现有玻璃和过渡保留。

没有新的明确授权，代理不操作手机、ADB、真实账号或发布后台。后续新版本Android code须大于39，原冻结APK／源码ZIP不要覆盖。
