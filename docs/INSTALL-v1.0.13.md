2. 分别检查歌曲、听书、本地音乐、酷狗音效筛选和网易云选择器的底部玻璃搜索，覆盖输入、清空、返回、键盘升降和页面切换。

5. 用户主动授权录音或选择文件后，检查识曲、图片和音频上传；本地原文件和其他平台账号应保留。
6. 与另一位真实用户分别检查一起听创建、邀请、队列、播放状态、离开与后台停止同步；本机主机测试没有完成双端验收。
