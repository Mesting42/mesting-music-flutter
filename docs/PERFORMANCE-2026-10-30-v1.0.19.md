# 1.0.19 切页性能处理与证据范围

用户提供的 1.0.18/code39 诊断记录：120Hz、1080×2400、DPR 2.625、浅色、约 50 秒，共 3854 个记录帧。构建 p50 1.504ms、p95 3.550ms，87 帧超过约 8.33ms；绘制 p50 7.097ms、p95 26.295ms，1519 帧超过约 8.33ms、352 帧超过约 16.67ms。此记录支持优先检查绘制与图片开销，不能单凭总帧数计算持续应用帧率，亦不能证明某个单一玻璃控件是全部根因。

匿名公开图片检查：歌手榜样本原始图片 Content-Length 为 10,082,816 字节；同路径 param=510y510 响应 200/image/jpg、299,640 字节。只对该样本而言，传输量减少约 97%。这不是整站、所有图片或手机 FPS 的提升比例。

1. 统一图片请求先使用网易云 CDN 有界缩略图，覆盖个人页歌单与歌手栏，减少原图传输和大纹理解码/上传；其他主机保持其原始地址。
2. 磁盘缓存区分尺寸，地址签名刷新不重复创建同尺寸文件；控件尺寸变化会重新加载合适变体。
3. 可选推荐栏等待页面入场完成再启动请求，防止图片解码与玻璃/页面转场同时争用资源。专门回归验证入场中不加载、完成后加载、反向退出不重新展示占位。
4. 玻璃材质、光学质量、普通按钮弹簧、手势返回和转场时间保持；没有启动手机、ADB 或原生性能测试，没有运行日常包的 flutter drive。

本轮最终证据为主机回归、静态分析、公开缩略图请求及浅/深色 320/390 宽布局检查。新 APK 在用户手机上的绘制分位数、温度、持续刷新率与实际体感尚待相同路径复测；不声称已经达到持续 120fps。
