# 1.0.21 / code42 修改与验证范围

本轮针对用户报告的连续快速切tab原生闪退与页面卡顿，扩大到四个tab、歌曲/歌单列表、歌手/专辑、搜索、完整播放器、歌词及队列。用户已确认方案；正式名称、安装包身份、原签名、玻璃与动画保持。

1. **导航调度**：`BetaTabNavigation`首个请求立即导航，真实360ms路由动画未完成时只保留最新目标；完成信号再派发最终请求。详情、搜索、播放器等显式导航取消旧的排队目标。防止连续输入累积多层离场路由，测试覆盖过期完成信号、同页取消及从详情返回。
2. **播放器内容树**：`PlayerContentTransition`同时最多保留一棵进入和一棵退出内容，反向切换复用已挂载状态，退出内容停止命中、语义和ticker。保留360ms进入、280ms退出的原渐变、位移和缩放曲线，测试覆盖中断与反向状态。
3. **几何纹理复用**：内置已知shader按精确尺寸、DPR、材质参数、形状顺序、圆角与变换缓存几何matte。LRU最多48项/2M像素、单项256K像素，保留独立ui.Image句柄，内存压力清空。只缓存初始/静止几何，变化中的形状继续生成；未知自定义shader默认不进入共享缓存。没有缓存过时背景或改动光学shader。
4. **滚动胶囊**：`BetaScrollChrome`将一次300ms形变期间的目标合并为最新状态，保留滚动迟滞和正常动画；显式导航/搜索立即复位。减少上下快滑重复重启同一形变，定时器随组件释放。
5. **公开封面请求**：实测手机对Dart默认标识、组合标识或两个User-Agent字段返回403，同图单独应用标识返回200。Flutter IO NetworkImage使用`headers.add`，追加后仍带Dart标识；原1.0.20的磁盘缓存路径使用`package:http`的header替换，因此两条路径行为不同。新增局部`ArtworkNetworkImage`统一直接加载与缓存请求的单个应用标识，其他CDN/签名URL仍走原NetworkImage。喜欢封面的预加载也使用同一入口。保留Flutter解码尺寸、图像缓存、缺图占位和既有有限重试；诊断只增加HTTP状态，绝不输出完整URL/凭据。

`test/release_121_*`覆盖导航、滚动调度、两棵内容树/退出曲线、精确几何key/句柄/容量/内存压力、真实本机HTTP单标识/解码/403后重试。新增代码按调度、渲染缓存和图片传输分离，关键所有权和限制有注释。旧数据测试的临时目录清理仅忽略已被下载清理任务移除的目录，不吞其他错误。

主机最终数量以本版validation为准。七场景原生profile和日常包页面路径已复测，详见[性能与闪退边界](PERFORMANCE-2026-10-30-v1.0.21.md)。快速tab与歌词滚动改善，但歌曲列表约20ms尾帧仍存在；驱动闪退在有限测试未复现，根因和长期稳定性仍未证明。不能把通过回归、页面能操作或一次未闪退写成全App持续120fps。

正式双ARM包不启用`MESTING_LOCAL_DIAGNOSTICS`，不打入集成测试插件或生成歌词夹具。完整源码不含手机截图、私有日志、候选包、密钥和本机SDK配置。旧冻结交付及全部未提交工作保留；未操作Git提交/推送、GitHub Release或music后台。
