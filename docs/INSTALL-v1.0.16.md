# 1.0.16 / code37 用户安装与复测

使用最终 `D:/AnLi/release/Mesting-Music-v1.0.16.apk`，校验同目录 verification 与 SHA256。正式名称 Mesting Music、包名 `com.mesting.music.beta`，保持原签名；请自行覆盖安装，保留应用数据。不要使用build临时包。

1. “网易云播放与同步”开启备用音源，确认B站视频音轨开启，备用最低码率先选“不限”。“允许无损”可以保留开启；这表示允许尝试，不代表所有来源都会提供无损。
2. 开启音源诊断，点播薛之谦《我好像在哪见过你》《陪你去流浪》。主机已得到约281秒/274秒音轨，但手机网络、CDN和系统解码需本次复测。B站AAC音轨不能显示为FLAC或320k MP3。
3. 检查播放超过原试听区间，测试拖动到后半段、暂停恢复、连续切歌、后台与输出设备；确认不会播旧选择或出现短提示音。
4. 如再次闪退，重新打开App，在同一设置中开启音源诊断，复制JSON；Android11及以上会在系统有记录时附加本应用历史异常退出原因。历史原因不标注为当前版本，缺少记录也不等于没有闪退。无需连接ADB或交出账号。
5. 检查下载、浅深色、底部玻璃搜索与按钮起手滚动。其他网易云账号消息、播放入云与官版一起听仍按此前待验收范围保留。

本次仅本地交付，没有上传music或Git归档。用户自行发布时使用本版release-notes.txt与publish.json的配套字段，不重复使用code36资料。
