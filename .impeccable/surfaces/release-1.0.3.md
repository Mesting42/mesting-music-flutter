The user's existing haptic/update screenshots and DESIGN.md are the authority.

## Direction contract

THESIS: Every control has an honest state: disabled stays readable, saved
profile data belongs to the right account, and audio tools change real playback.

OWN-WORLD: Neutral white/near-black pages, grouped surfaces, blue functional
actions, Cupertino pickers, 48dp independent premium glass navigation/actions.
Existing blur/refraction/deformation, capsule motion and theme ownership stay.
Chinese system typography, 22dp content insets, generous section spacing,
scrollable short/large-text layouts and bounded wide-screen content continue.

STORY: Settings or player More opens an audio tool. The account card opens six
profile fields; only an explicit save/upload writes to Kugou. Region is an
offline province/city picker with original values preserved. Update shows
version-specific notes even when current. MV borrows focus from the one music
owner and restores it only if later transport intent has not superseded it.

FIRST VIEWPORT: One title with a circular back lens. Profile leads with avatar
then nickname and grouped identity pickers. EQ leads with a blue enable switch,
gain graph, saved preset and actual hardware bands. Effects leads with catalogue
segments and a searchable loaded list. MV leads with the real video frame.
Sleep retains the existing glass-sheet grammar and one explicit start action.

FORM: Existing native component system and code-led refinement; no dashboard
template, new palette, decorative imagery or alternate brand world.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

  and enabled semantics, active-only haptic preview, no scroll press residue.
- Six profile fields only; JSON-body writes, no retries on account writes,
  dirty-only payloads, failed drafts retained and stale-account responses rejected.
- EQ acts on the current native music session, with device bands, bounded init,
  persisted choices, visible pending/error states and no second audio owner.
  User refinement: the five visible slider thumbs are 6dp on a 2dp track;
  hit targets remain 48dp, with dB semantics and existing drag behavior.
- Free upstream effects use its EQ mapping; no claim of IRS/VPF convolution.
- Timer stops the actual owner and suppresses automatic Next; native repeat-one
  is temporarily disabled for the end-of-song boundary and restored afterward.
- MV uses actual metadata/URL routes and returned qualities, pauses music,
  releases superseded video controllers and honours later music/timer commands.

  catalogue and MV frame; Windows QA font overrides never enter the APK.
